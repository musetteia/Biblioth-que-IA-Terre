## Étapes communes

1. Téléchargez l'archive `.zip` de l'application depuis la fiche, puis décompressez-la. Gardez les fichiers ensemble, sous leurs noms d'origine.
2. Ouvrez une conversation dans votre propre compte Claude (un compte qui sait publier des artefacts) et joignez-y tous les fichiers de l'archive.
3. À remplacer — envoyez le message de publication : « Publie ces fichiers comme un artefact : `index.html` est la page d'entrée, et les autres fichiers doivent être servis à côté, sous les mêmes noms. » puis la déclaration des capacités demandées.
4. Ouvrez l'artefact créé. La première fois, la page demande l'autorisation d'utiliser Claude : chaque appel compte sur votre forfait Claude.

## Claude

Suivez les étapes communes dans Claude.
