## Étapes communes

1. Téléchargez l'archive `.zip` de l'application depuis la fiche, puis décompressez-la. Gardez les fichiers ensemble, sous leurs noms d'origine.
2. Ouvrez une conversation dans votre propre compte Claude (un compte qui sait publier des artefacts) et joignez-y tous les fichiers de l'archive.
3. Envoyez ce message : « Publie ces fichiers comme un artefact : `index.html` est la page d'entrée, et les autres fichiers doivent être servis à côté, sous les mêmes noms. Déclare ensuite les 2 capacités pour cet artefact : la base de données (`db`) avec la règle d'accès `{"path": "", "read": "admin", "write": "admin"}` et l'appel à Claude (`sample`). »
4. Ouvrez l'artefact créé. La première fois, la page demande l'autorisation d'utiliser Claude : chaque appel compte sur votre forfait Claude, comme un message dans le chat.
5. Utilisez d'abord des données fictives : l'application tourne chez vous, et ses données restent dans votre compte.
6. Relisez et vérifiez toujours ce que l'IA produit avant de l'utiliser.

Les noms des menus changent selon les versions des outils : en cas de doute, consultez l'aide de votre outil.

## Claude

Suivez les étapes communes dans Claude.
