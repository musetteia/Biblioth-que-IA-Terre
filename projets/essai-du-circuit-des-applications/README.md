## Le problème résolu

Vérifier de bout en bout que le site sait recevoir, valider et publier une application qui s'installe dans le propre Claude de l'utilisateur.

## Entrées et sorties

- **Ce que vous donnez** : Rien : un clic sur un bouton.
- **Ce que vous recevez** : Une phrase courte écrite par Claude, enregistrée puis listée avec les quatre précédentes.

## Limites connues

- Application d'essai sans autre intérêt que le test.
- Chaque appel compte sur le forfait Claude de l'utilisateur.
- Les phrases sont enregistrées dans sa base personnelle, visible de lui seul.

Adaptez les exemples et les consignes à votre cas, sans y mettre de donnée sensible.
