# Essai du circuit des applications

Cette application ne sert qu'à vérifier que le circuit de dépôt, de validation et d'installation des applications fonctionne. Elle demande à Claude une phrase courte, l'affiche, puis l'enregistre dans votre base de données personnelle ; les cinq dernières phrases sont listées.

## Contenu de l'archive

| Fichier | Rôle |
|---|---|
| `index.html` | la page d'entrée |
| `app.js` | le code de l'application |
| `style.css` | la mise en forme |
